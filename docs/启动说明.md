# 启动说明

拿到压缩包后，按下面四步就能在本机跑起来。全程只需要 Python，不需要 Node、数据库或 Docker。

## 0. 环境要求

- Windows / macOS / Linux 均可（本文命令以 Windows PowerShell 为例）
- **Python 3.10 或更高版本**，安装时勾选「Add Python to PATH」
- 首次 `pip install` 需要联网下载依赖（fastapi / uvicorn / httpx / python-dotenv，都很小）

验证 Python 版本：

```powershell
python --version
```

## 1. 解压并进入项目目录

```powershell
cd D:\code\ecom-cs-agent
```

## 2. 创建虚拟环境并安装依赖

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

macOS / Linux 用：

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
```

> 也可以直接运行项目根目录的 `start.ps1`，它会自动完成「找 Python → 建 venv → 装依赖 → 生成 .env → 启动」的全过程。

## 3. 准备配置文件

把示例配置复制成真正的配置文件：

```powershell
Copy-Item .env.example .env
```

然后按需编辑 `.env`：

```ini
# 真实模型模式：填 zhipu 并填入你的 Key
PROVIDER=zhipu
API_KEY=你的Key

# 留空则走本地演示模式（不调用外部模型，用内置话术 + 本地检索）
```

**两种运行模式**：

| 配置 | 模式 | 表现 |
| --- | --- | --- |
| `API_KEY` 有值 | `live` 真实模型 | 走 zhipu `glm-4-flash`，模型自己决定是否调工具 |
| `API_KEY` 为空 | `demo` 演示模式 | 不联网、不花钱，规则 + 内置话术回复，用于快速看流程 |

**不填 Key 也能跑**：演示模式覆盖查订单、退换货政策、规格问答、转人工这些主流程，适合只想看界面和链路的人。真实模型模式只是把「决策」交给模型，不影响其他层。

## 4. 启动

```powershell
.\.venv\Scripts\python.exe -m app.main
```

看到类似输出即启动成功：

```
Uvicorn running on http://0.0.0.0:8000
```

## 5. 访问

浏览器打开：

```
http://127.0.0.1:8000
```

健康检查（确认当前模式）：

```
http://127.0.0.1:8000/health
```

`/health` 里看 `mode` 字段：`live` = 真实模型，`demo` = 演示模式。

可以试着问：

- 「帮我查一下尾号 8821 的订单」
- 「退换货政策是什么」
- 「耳机重量多少」
- 「你们领导在吗」

## 常见问题

### Q1：端口 8000 被占用怎么办？

不用手动改。程序启动时会从 `PORT`（默认 8000）开始逐个尝试，**被占用就自动顺延**到 8001、8002……最多试 11 个端口，实际端口会打印在控制台，同时写入 `logs/server_url.txt`。以控制台输出的地址为准即可。

如果确实想指定端口，改 `.env` 里的 `PORT=8001`。

### Q2：PowerShell 提示「无法加载文件 start.ps1，因为在此系统上禁止运行脚本」

这是 Windows 默认执行策略拦截，不是脚本有问题。用当前窗口临时放开即可（不改系统全局设置）：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\start.ps1
```

或者完全不碰策略，手动执行第 2～4 步的命令。

### Q3：`python` 命令找不到

安装 Python 时没勾选 Add to PATH。两个办法：重新安装并勾选；或直接用绝对路径，例如：

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -m venv .venv
```

### Q4：`pip install` 很慢或超时

换国内镜像源：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q5：检索结果显示「降级 BM25」

正常现象。embedding 接口需要额外额度，额度不足时会自动降级为本地 BM25 关键词检索，功能不受影响，`/health` 的 `retrieval.degraded` 会标为 `true`。

### Q6：日志在哪

`logs/` 目录。启动地址记录在 `logs/server_url.txt`，对话与转人工记录也在该目录下。这些文件不会打进分发包。
